# Customer Insights Dashboard

An interactive customer and sales analytics dashboard developed using Microsoft Power BI.

The project focuses on transforming raw business data into an interactive report through data cleaning, transformation, DAX-based analysis, visualization, and dashboard design.

## Project Overview

The dashboard provides an interactive view of customer, product, geographical, and sales performance.

It enables users to analyze:

* Customer and product metrics
* Sales trends over time
* Sales by individual product
* Sales distribution by product category
* Country-level performance
* State-level performance
* Filter-based changes in business metrics

## Tools and Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning and Transformation
* Data Visualization
* Interactive Dashboard Design

## Data Preparation

The dataset was cleaned and transformed using Power Query before building the analytical report.

Key activities included:

* Data cleaning
* Data type handling
* Data transformation
* Preparing fields for analysis
* Structuring data for visualization

## DAX and Analysis

DAX was used to create calculations and KPI values required for the dashboard.

The project provided practical experience with:

* Measures
* Aggregations
* KPI calculations
* Filter context
* Dynamic analysis based on user selections

## Dashboard Components

### KPI Cards

Displays key metrics including:

* Total Customers
* Total States
* Total Products

### Sales Trend

A line chart showing sales performance across years and quarters.

### Sales by Product

A horizontal bar chart comparing sales across individual products.

### Sales by Product Category

A donut chart showing the contribution of different product categories to total sales.

### Interactive Filters

The report includes filters for:

* Year
* Order Date
* Country
* State

These filters dynamically update the dashboard visuals.

## Dashboard Design

The dashboard was designed using a consistent blue-based color palette.

Different shades and saturations of blue were used to distinguish categories while maintaining a unified visual identity.

The design process focused on:

* Color consistency
* Visual hierarchy
* Contrast
* Spacing
* Alignment
* Typography
* Readability
* Consistent visual styling

The objective was to maintain a clean interface while making important information easy to identify.

## Key Learning Outcomes

This project provided practical experience across the complete Power BI workflow:

```text
Raw Data
   ↓
Data Cleaning
   ↓
Power Query Transformation
   ↓
DAX Calculations
   ↓
Data Visualization
   ↓
Interactive Dashboard
   ↓
Business Insights
```

Key areas learned through the project:

* Data cleaning and transformation using Power Query
* Creating analytical measures using DAX
* Building KPI cards
* Selecting appropriate visualizations
* Creating interactive slicers
* Understanding filter-driven analysis
* Designing a consistent color palette
* Applying visual hierarchy and spacing
* Presenting data in a business-oriented format
